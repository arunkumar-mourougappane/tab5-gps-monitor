Simulation

What you're tapping

Three toggles, one layout

The panel has a single layout with three switches on it — position view, log expansion, and the brightness overlay. Everything below is reachable from anywhere in one tap.

Accuracy carries its own trend

The HDOP readout is followed by the last 40 valid readings on a fixed 0–5 scale, in the space the PDOP/VDOP caption used to hold. A single number can't say whether a fix is settling or degrading, which is the question this block exists to answer; the full DOP trio is still in the sentence stream and the SD log. The scale is fixed deliberately — a trace that autoscaled would make a steady poor fix look like a steady good one.

Position card → trip stats

Tapping the card swaps live coordinates for accumulated distance, max and average speed, trip time and time-to-first-fix, with the same HDOP trend at full card width. The sky plot and stream keep updating behind it.

Satellite dots

34 px pick radius against dots drawn at 4–9 px, because a fingertip covers about 40 px on this panel. It picks the nearest dot, not the first qualifying one — satellites cluster at the zenith and the tooltip names one specific vehicle. It expires after four seconds.

NMEA card → full height

Expanding steps the log up to 22 px and drops the counter column: a long GSV sentence runs to roughly 980 px at that size, wider than the 968 px the counters leave behind.

Filter chip

Cycles ALL → NO GSV → POS and clears the ring buffer, so you never see a mix of pre- and post-filter sentences. It is a view control only — SD logging, the TCP stream and the sky plot still see every sentence.

LIGHT

Opens a modal brightness overlay. Drag anywhere on the track; the level follows the finger rather than waiting for release. The slider floor is 8/255 — going fully dark is OFF's job, since a slider that blanks the screen leaves no way back to itself.

SLEEP

Blanks the panel and drops the Wi-Fi AP. Ingestion, SD logging and trip stats keep running — for a logger, screen off means keep recording in your pocket. Tap anywhere to wake; that tap is consumed rather than hitting whatever was underneath.

Palette

rgb565 · src/main.cpp

Twelve colours, declared once as constexpr and quantised to 16 bits at compile time. Swatches show the source RGB; the code beneath is what the panel receives.

Touch map

Evaluated in this order, on release

Hit testing runs top of the list first, so a chip sitting inside a card resolves before the card underneath it. Edge detection is done by hand rather than through wasClicked(): this digitiser emits a ghost second contact, and its detail slots hold stale data once a release reports zero points.
